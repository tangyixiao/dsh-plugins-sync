项目里的主要内容

  • 插件目录快照

    保留上游逐插件 YAML 元数据及扁平索引。

  • 下载与 stars 排行

    按快照中的下载和 stars 数据生成可读排行。

  • 指定 profile 的精选安装

    精选安装目标钉死 npm 版本或 Git 提交，并指定 profile。
